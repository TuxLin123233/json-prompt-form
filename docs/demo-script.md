# 30 秒演示脚本

目标：让人在 30 秒内看懂「选模板 → 复制 → 聊天 → 存档 → 下次续接」。

## 画面规格

- 竖屏 1080×1920，30fps，15–30 秒。
- 录屏 + 大字幕，不用真人出镜。
- 背景音可用轻音乐，音量压低。
- 所有示例数据用虚构内容，避免暴露隐私。

## 分镜

| 时间 | 画面 | 字幕 |
| --- | --- | --- |
| 0–3s | 黑底白字，或网页 AI 聊天框淡入 | 网页版 AI，聊完就忘？ |
| 3–6s | 打开 GitHub Pages 首页 | 选一个场景 |
| 6–9s | 搜索「焦虑」，点「复制模板」 | 一键复制 |
| 9–13s | 粘贴到 DeepSeek，补一句「今天是 11 月 15 日，我……」 | 整份粘贴，再说你的情况 |
| 13–18s | 快速展示 AI 生成功能、聊两句 | 它会按你的情况设计功能 |
| 18–22s | 输入「存档」，展示 ```json 代码块 | 聊完说「存档」 |
| 22–25s | 复制 JSON，保存到备忘录 | 把存档收好 |
| 25–30s | 新会话粘贴「今天日期 + 存档」，AI 接着聊 | 下次贴回来，接着来 |

## 字幕模板

- 开头钩子：`网页版 AI 聊完就忘？`
- 核心卖点：`一个 JSON，让它长期记住你`
- 行动号召：`搜 json-prompt-form，或点主页链接`

## 录制建议

1. 用干净的浏览器窗口，关掉无关标签和通知。
2. 浏览器缩放 110%–125%，手机上看得清。
3. 复制动作要有反馈：出现「已复制 ✓」提示。
4. 存档代码块至少停留 2 秒，让观众看清。
5. 最后 2 秒放二维码或网址，方便截图。
